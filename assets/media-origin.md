# Asset sources and licenses

- `html/assets/backgrounds/desk.png`: AI-generated wooden desk background.
- `html/assets/audio/page-turn.mp3`: maintainer-supplied page-turn recording; no separate license is documented.
- `html/style/fonts/maoken-handwriting-0.20.ttf`: Maoken handwriting font, OFL. See `maoken-ofl.txt` and `maoken-attribution.md` in the same directory.
- `html/style/fonts/source-serif-4-*.woff2`: Adobe Source Serif 4, OFL. See `ofl-license.md` and `source.txt` in the same directory.
- `html/vendor/page-flip.browser.js`: PageFlip by Nodlik, MIT. See `html/vendor/page-flip-license.txt`.
- `demo/photo-flipbook-demo.mp4` and `.gif`: maintainer-provided album demonstration for the README; not included in generated books.

The project MIT license does not override separate third-party licenses or grant rights to assets the maintainer cannot license.

The runtime template is adapted from [create-photo-flipbook-ui](https://github.com/HaichaoLihc/create-photo-flipbook-ui) by Haichao Li (MIT). Its original notice is preserved in `html/vendor/create-photo-flipbook-ui-license.txt` and included in generated books.
